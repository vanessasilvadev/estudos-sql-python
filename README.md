# Estudos de SQL com Python

Mini-projeto de estudo feito durante minha transição de carreira para
Engenharia de Dados e IA. O programa cria um banco de dados SQLite,
insere dados de vendas de uma loja fictícia e usa SQL para calcular
o faturamento por categoria.

## O que eu pratiquei
- Criar banco e tabela com Python (`sqlite3`)
- Inserir dados com `INSERT`
- Consultar com `SELECT`, `SUM`, `GROUP BY` e `ORDER BY`

## Requisitos
- Python 3.8 ou superior (o módulo `sqlite3` já vem incluído, não há dependências externas)

## Como rodar
```
python main.py
```

## Resultado esperado
```
Acessórios: R$ 719.20
Informática: R$ 585.00
Papelaria: R$ 275.00
```

## Tecnologias
Python, SQLite, SQL
